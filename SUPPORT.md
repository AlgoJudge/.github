# Getting help

- **Installing, configuring, or using AlgoJudge:** start with the documentation
  at [docs.algojudge.pl](https://docs.algojudge.pl/). Problems with an
  installation are covered in
  [Troubleshooting](https://docs.algojudge.pl/en/install/troubleshooting/).
- **Something does not work as documented:** open an issue in the repository
  that owns it, using the bug report form. [CONTRIBUTING.md](CONTRIBUTING.md)
  lists the repositories.
- **Anything else:** email contact@algojudge.pl.

Report security vulnerabilities privately, as described in
[SECURITY.md](SECURITY.md), not in an issue.
