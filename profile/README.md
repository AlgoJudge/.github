# AlgoJudge

A system that supports programming contests and courses based on programming problems and automatic evaluation of solutions.

## Repository map

- [AlgoJudge-Server](https://github.com/AlgoJudge/AlgoJudge-Server) is a server that stores data and provides REST API, developed in C# with ASP.NET Core (.NET 8).
- [AlgoJudge-Client](https://github.com/AlgoJudge/AlgoJudge-Client) is a client web app developed in TypeScript using React.
- [AlgoJudge-Runner](https://github.com/AlgoJudge/AlgoJudge-Runner) is an app that runs and evaluates solutions.
